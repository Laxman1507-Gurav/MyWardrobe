# MyWardrobe – Digital Wardrobe & AI Stylist

MyWardrobe is a digital wardrobe management and outfit styling platform that helps users organize their clothing collections, create outfits, schedule daily looks, and discover personalized outfit recommendations.

## Features

* Digital wardrobe management
* Add, edit, and delete clothing items
* Categorize clothes by type, colour, season, and occasion
* Create and save outfit combinations
* Personalized outfit recommendations
* Outfit calendar and scheduling
* Favourite outfits
* Laundry and clothing availability tracking
* Wardrobe analytics
* Secure user authentication

## Technology Stack

* Frontend: React.js
* Backend: Java Spring Boot
* Database: MySQL
* ORM: Spring Data JPA / Hibernate
* Authentication: Spring Security and JWT
* UI: Tailwind CSS
* Animations: Framer Motion

## Project Purpose

The goal of MyWardrobe is to transform traditional wardrobe management into a convenient digital experience while helping users make better outfit choices.
